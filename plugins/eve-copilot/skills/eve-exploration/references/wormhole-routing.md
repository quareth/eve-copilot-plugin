# Wormhole routing

Wormhole exploration is live graph discovery. Public ESI jump and kill
snapshots exclude wormhole systems, and SDE data does not contain the current
random chain. Do not score a J-space node as quiet because no ESI row exists.

## Required live chain state

Obtain from pilot observations, accessible bookmarks, or an explicitly
authorized private mapper:

- both-side bookmarks and signature IDs;
- origin and destination system or class clues;
- connection lifetime, remaining mass, and maximum ship size;
- polarization state for relevant pilots;
- ships, probes, wrecks, structures, and customs-office ownership on D-scan;
- visible signatures, scanned sites, visited branches, and occupancy evidence;
- a credible return or alternate extraction path.

If the MCP can retrieve a bookmark or private-map fact, do so before asking.
Otherwise ask only for the observation that changes the current decision.

## Arrival procedure

1. Hold session cloak and bookmark the new side.
2. Identify the system and connection before moving away.
3. D-scan before launching probes; use more than one vantage point in large
   systems.
4. Record ships, probes, wrecks, structures, customs offices, and signatures.
5. Reconcile the branch in the map or expedition state.
6. Scan, run, wait, branch, or leave based on site eligibility and extraction
   credibility.

Two or more systems deep, use a mapper or explicit chain state. Memory and a
flat destination list are not a reliable return plan.

## Route policy

- Favor stable branches with multiple options while a credible extraction
  path remains.
- Reject a required round trip through an end-of-life, critically disrupted,
  size-incompatible, or otherwise unsuitable connection.
- Account for the mass of every committed hull; a cruiser fleet changes the
  connection budget more than a scanning frigate.
- Treat convenient high-sec entries as potentially more visited, but label
  this a heuristic and verify it live.
- Use public Thera or Turnur links as timestamped transit edges, not promises of
  untouched sites or guaranteed exits.
- As loot accumulates, chain depth grows, or connection condition worsens,
  shift from opportunity toward extraction.

Never send a pure hacking frigate into a site containing Sleepers or an
unclassified hazard merely because the cans are scannable.
